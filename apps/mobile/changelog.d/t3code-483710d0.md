### Added

- You can react to a message with an emoji, and you can see the reactions of you and your agents under each message.
- Select part of an agent's reply to Explain, Improve, Shorten, change the Tone or fix the Grammar of it, as in the desktop app. Touch and hold the reply, or tap Select text under it. To describe your own edit, write it in the message box. Tap outside the reply, or tap Select text again, to end the selection.
- Queued messages show above the message box, with Steer and Edit on each message.

### Changed

- Copy, React, Reply, Select text and the time are now in a row under each message. Before, they were in a sheet that opened only when you touched and held a message.
- You now select text in the reply itself. Before, the text opened in a separate sheet.
