### Changed

- The chat scrolls more smoothly, mostly in long chats with tables, code and media. It now draws only the messages near the screen, and a message that you send moves to the top of the chat in one movement.
- During a fast scroll, a page preview, a diagram, a video and code colours wait until the chat slows down, so the scroll does not stop for them.

### Fixed

- On Android, scrolling a long chat with code or file names in the replies was slow and dropped frames. Code and file names now stay in the text of their paragraph.
