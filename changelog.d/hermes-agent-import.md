### Added

- Import your Hermes Agent profiles in Server settings › Import on this computer. Each profile becomes an agent with its persona, memories, skills and scheduled jobs. Before anything changes, you see every item and why an item stays in Hermes. Skills with scripts and MCP servers import only when you allow them, and MCP servers are added turned off. Keys in `.env` are never copied. When you import a profile again, its agent is updated, and no second agent is added.
- Server settings › Import now starts with where your agents are now: Hermes Agent, Grok Bot, or another OpenBot computer.
