### Added

- Settings > Transfer moves your agents to another computer. Export one file on the old computer and import it on the new one. The file holds the instructions, avatar, model, skills, routines and memories of each agent and, if you want, its workspace files, plus your MCP servers, model providers, preferences and sidebar sections. API keys, sign-ins and chat history are not in the file. After the import, OpenBot shows which providers to sign in to again.
